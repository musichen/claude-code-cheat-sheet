# Contributing

Thanks for contributing to claude-code-cheat-sheet.

## Setup

Clone the repository and install dependencies as described in the README.

## Making changes

1. Fork the repository or create a topic branch from `main`.
2. Make your change, keeping it focused on one topic.
3. Run the project's checks or manual smoke test described in the README.
4. Open a pull request with a clear summary of what changed and why.

## Reporting bugs

Open an issue with steps to reproduce, expected and actual behaviour, and your environment.
